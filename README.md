# Élan · 创作者社交中枢（账号版）

深色界面、单一强调色（琥珀）的社交页面，带真实可用的**本机多账号系统**：管理员建号、各自独立发帖、账号之间像微信一样私信。

## 打开

双击 `elan-social.html`，无需构建、无后端、无外部依赖（字体 CDN 失败会自动回退）。

- 线上：https://yz333zy.github.io/12134/elan-social.html
- 仓库：https://github.com/Yz333zY/12134

## 账号体系

**首次打开**会让你创建第一个账号，它自动成为管理员。之后每次进入是「选择账号 + 密码」的登录门。

| 能力 | 说明 |
|---|---|
| 管理员建号 | 昵称、账号（唯一 handle）、密码、身份（管理员/成员）、职位、简介 |
| 编辑账号 | 改任何人的昵称/账号/身份/资料；改密码单独一条「改密码」 |
| 删除账号 | 连带删除 TA 的动态、评论、私信；不能删自己，也不能删掉最后一个管理员 |
| 公告 | 管理员发布/删除全站公告，同步到公告页与右栏 |
| 数据重置 | 管理员在设置里「清空本机数据」，回到首次使用状态 |

**每个账号完全独立**：时间线、点赞、收藏、评论、私信、偏好（字号/密度/动效/右栏）都按账号分开存。换账号登录就换了一份数据。

## 私信（微信式）

「最新消息」页是双栏：左边会话列表（未读红点、最后一条消息），右边聊天窗口；没聊过的人列在「发起新对话」里，点一下就能开聊。消息只对会话双方可见——换个账号登录看不到别人的对话。

## 数据与安全边界

- 全部数据存在浏览器 `localStorage`，键名 `elan.v3`（`elan-state` 之类的旧键会在启动时清掉）。
- 密码是加盐哈希后存的，但**这是本机客户端存储，不是服务器**：能打开这台电脑的人就能读 localStorage。它挡的是"随手点开一个账号"，不是攻击者。
- 换浏览器、换设备、清缓存 = 数据消失，没有同步、没有找回。
- 想接真实后端：`elan-data.js` 里的 `createUser / login / addPost / sendMsg` 是唯一的写入口，替换成 API 调用即可，`elan-app.js` 不用动。

```

elan-app.js                 业务层：登录门、时间线、私信、成员目录、管理台、资料、设置、搜索
elan-enhance.css            基础增强样式（弹层、评论、设置）
elan-accounts.css           账号层样式（登录卡、私信双栏、成员卡、管理台）
build-elan.mjs              构建：原始页 + CSS + 三个 JS → elan-social.html
docs/                       截图
```

## 重新构建

```bash
node build-elan.mjs
```

只改 `elan-*.js` / `elan-*.css`，不要手改产物。构建把字体样式表改成非阻塞加载，然后把 CSS 与三个脚本按顺序注入 `</body>` 之前。

## 键盘

`/` 聚焦搜索（账号与动态混排，↑↓ 选择、Enter 打开）、`Ctrl/⌘ + Enter` 发布、`Esc` 关闭弹层。

## 兼容性

现代 Chrome / Edge / Safari / Firefox。用了 `dvh`、`backdrop-filter`、`localStorage`、`canvas`（图片压缩到 1000px / JPEG 0.82，避免撑爆配额）。

# Élan · 创作者社交中枢

单文件前端演示：深色界面、单一强调色（琥珀）、合成器动画。原文件是一个纯静态 mock，本仓库在其上加了一层真实可用的增强层（设置、发帖带图、评论、私信、帖子菜单、资料编辑、本地持久化、全设备自适应）。

## 在线体验

直接双击打开 `elan-social.html` 即可，无需构建、无外部依赖（字体从 CDN 加载，失败时回退系统字体，且不阻塞渲染）。

## 功能

- **发布**：最多 4 张图片（本地选择 → 预览 → 随动态展示）、插入链接、图表占位；`Ctrl/⌘ + Enter` 发布
- **评论**：帖子内展开评论区，回车发送，计数同步
- **私信**：好友资料 →「发消息」打开聊天抽屉，可发送并收到自动回复，按好友分别存档
- **帖子菜单**：复制链接 / 收藏 / 隐藏 / 删除
- **编辑资料**：昵称、账号、简介，保存后同步个人页、侧栏与头像首字
- **设置**：正文字号、紧凑排版、减少动效、显示/隐藏右侧栏
- **持久化**：点赞、收藏、动态、评论、私信、隐藏/删除、资料、偏好全部写入 `localStorage`（键 `elan.state.v1`）
- **键盘**：`/` 聚焦搜索，`↑ ↓` 选择结果，`Enter` 打开，`Esc` 关闭
- **全设备自适应**：1440 四栏 / 1280 收起右栏 / 1024 收起侧栏 / ≤820 单栏 + 底部导航 / ≤480 细调排版

## 目录结构

```
elan-social.html          构建产物（直接打开）
elan-social.original.html 原始 mock（构建输入的基准）
elan-enhance.css          增强层样式（含响应式断点）
elan-enhance.js           增强层脚本（功能与持久化）
build-elan.mjs            构建：原始文件 + 增强层 → elan-social.html
docs/                     截图
```

## 重新构建

```bash
node build-elan.mjs
```

脚本以 `elan-social.original.html` 为基准，把 `elan-enhance.css` 和 `elan-enhance.js` 以字面量方式插入 `</body>` 之前，并把 CDN 字体改为非阻塞加载。改动只需要动增强层源码，不要直接改构建产物。

## 兼容性

现代浏览器（Chrome / Edge / Safari / Firefox 最新版）。使用了 `dvh` 单位、`backdrop-filter`、`IntersectionObserver`、`localStorage`。
